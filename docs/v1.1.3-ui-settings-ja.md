# PhotoShow v1.1.3 - UI設定の機能強化

## 概要

バージョン1.1.3では、ユーザーからのフィードバックに基づいて、2つの重要なUI カスタマイズ機能を追加しました：

1. **ビューモードインジケーターの表示設定** - 右上のモード表示（AUTO、FITなど）の表示/非表示を切り替え
2. **条件付き情報バーの表示** - すべての画像情報項目が無効の場合、下部の半透明バーを自動的に非表示

## 実装された要件

### ✅ 要件1: 右上のview modeを表示するかどうかの設定を追加

**実装内容:**
- 設定画面に「Show View Mode Indicator」チェックボックスを追加
- 場所：設定 → General タブ → 画像情報セクション
- デフォルト：有効（チェックあり）
- 動作：
  - 有効時：右上にモード表示（AUTO、FIT、LITE、MINIなど）が表示される
  - 無効時：モード表示が完全に非表示になる

### ✅ 要件2: image informationの項目がすべてdisableになっているとき一番下の部分の半透明の部分を消して

**実装内容:**
- 画像情報バー（下部の半透明オーバーレイ）の表示ロジックを改善
- 表示条件：
  - 「Show Image Info」が有効 AND
  - 少なくとも1つの項目（キャプション、寸法、フォーマット）に表示する内容がある場合
- 非表示条件：
  - 「Show Image Info」が無効 OR
  - すべての画像情報項目（キャプション、寸法、フォーマット）が無効の場合

**結果:** 空の半透明バーが表示されなくなり、真にミニマルなUIが実現できます！

## 使用シナリオ

### シナリオ1: すべて有効（デフォルト）
- **ビューモードインジケーター:** ✅ 右上に表示（例：「AUTO」）
- **情報バー:** ✅ 下部にキャプション、寸法、フォーマットを表示
- **適用場面:** すべての情報を表示したいユーザー向け

### シナリオ2: モード表示のみ無効
- **ビューモードインジケーター:** ❌ 非表示
- **情報バー:** ✅ 下部に表示
- **適用場面:** 自分のモードを知っていて、リマインダーが不要なユーザー向け

### シナリオ3: 情報バーのみ無効
- **ビューモードインジケーター:** ✅ 右上に表示
- **情報バー:** ❌ 非表示（すべての情報項目が無効）
- **適用場面:** モードは見たいが、画像の詳細は不要なユーザー向け

### シナリオ4: ミニマルUI（すべて非表示）
- **ビューモードインジケーター:** ❌ 非表示
- **情報バー:** ❌ 非表示
- **適用場面:** 邪魔にならない、クリーンでミニマルなインターフェースを好むユーザー向け
- **結果:** 画像のみが表示され、オーバーレイは一切なし ✨

## 設定方法

### ビューモードインジケーターの切り替え

1. ユーザースクリプトマネージャーのアイコンをクリック
2. 「PhotoShow Settings」を選択
3. 「General」タブを開く
4. 「Image Information」セクションを探す
5. 「Show View Mode Indicator」のチェックボックスを操作
   - チェックあり：右上にモード表示
   - チェックなし：モード表示が非表示
6. 「Save & Apply」をクリック
7. ページをリロード

### 情報バーを非表示にする方法

1. ユーザースクリプトマネージャーのアイコンをクリック
2. 「PhotoShow Settings」を選択
3. 「General」タブを開く
4. 「Image Information」セクションで以下をすべてチェックなしにする：
   - Show Caption（キャプションを表示）
   - Show Dimensions（寸法を表示）
   - Show Format（フォーマットを表示）
5. 「Save & Apply」をクリック
6. ページをリロード
7. 画像にホバーすると、下部の半透明バーが表示されません！

## 移行ガイド

### v1.1.2以前からのアップグレード

**操作不要！** 新しい設定には適切なデフォルト値があります：
- `showViewModeIndicator`はデフォルトで`true`（有効）
- 既存の設定は変更なしで動作します

**オプション:** ユーザーは設定UIから新しい設定をカスタマイズできます

### デフォルトにリセット

すべての設定をデフォルトにリセットする場合：

```javascript
// ブラウザコンソール（F12）を開いて実行：
window.resetPhotoShowSettings()
```

4. **優れたUX:** 空の半透明バーが表示されなくなった
5. **後方互換性:** 既存の設定は変更なしで動作
