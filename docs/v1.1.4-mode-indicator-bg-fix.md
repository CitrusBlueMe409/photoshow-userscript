# PhotoShow v1.1.4 - Mode Indicator Background Bug Fix

## 問題 (Problem)

**日本語:**
> show view mode indicatorをdisableにすると文字は消えますがその半透明の背景は残ってしまっているバグがあります

**English:**
When "Show View Mode Indicator" setting is disabled:
- ✅ The text (AUTO, FIT, LITE, etc.) disappears correctly
- ❌ The semi-transparent background box remains visible (BUG)

## 原因 (Root Cause)

### HTML構造 (HTML Structure)
```html
<div class="photoshow-viewer-controls">    <!-- 半透明の背景を持つコンテナ -->
    <span class="photoshow-mode-indicator">AUTO</span>  <!-- テキスト -->
</div>
```

### CSS (CSS Styles)
```css
.photoshow-viewer-controls {
    background: rgba(0, 0, 0, 0.6);  /* 半透明の黒背景 */
    color: white;
    padding: 4px 8px;
    border-radius: 4px;
}
```

### 問題のコード (Problematic Code)
```javascript
// 以前のコード - spanだけを非表示にしていた
const modeIndicator = viewer.querySelector('.photoshow-mode-indicator');
if (state.config.showViewModeIndicator) {
    modeIndicator.style.display = 'block';
} else {
    modeIndicator.style.display = 'none';  // テキストだけが消える、背景は残る！
}
```

**問題点:** `.photoshow-mode-indicator` span要素のみを非表示にしていたため、親コンテナ `.photoshow-viewer-controls` とその半透明背景は表示されたまま残っていました。

## 解決方法 (Solution)

### 修正後のコード (Fixed Code)
```javascript
// 修正後 - コンテナ全体を非表示にする
const modeIndicatorContainer = viewer.querySelector('.photoshow-viewer-controls');
const modeIndicator = viewer.querySelector('.photoshow-mode-indicator');
if (state.config.showViewModeIndicator) {
    modeIndicator.textContent = (state.currentViewMode || state.config.defaultViewMode).toUpperCase();
    modeIndicatorContainer.style.display = 'block';  // コンテナ全体を表示
} else {
    modeIndicatorContainer.style.display = 'none';  // コンテナ全体を非表示（背景も消える！）
}
```

**改善点:** 
- 親コンテナ `.photoshow-viewer-controls` を取得
- 設定が無効の場合、コンテナ全体を非表示にする
- これにより、テキストと背景の両方が消える

## Technical Details (English)

### Changes in photoshow.user.js (Line 580-588)

**Before:**
```javascript
// Update mode indicator
const modeIndicator = viewer.querySelector('.photoshow-mode-indicator');
if (state.config.showViewModeIndicator) {
    modeIndicator.textContent = (state.currentViewMode || state.config.defaultViewMode).toUpperCase();
    modeIndicator.style.display = 'block';
} else {
    modeIndicator.style.display = 'none';
}
```

**After:**
```javascript
// Update mode indicator - hide entire container to remove background
const modeIndicatorContainer = viewer.querySelector('.photoshow-viewer-controls');
const modeIndicator = viewer.querySelector('.photoshow-mode-indicator');
if (state.config.showViewModeIndicator) {
    modeIndicator.textContent = (state.currentViewMode || state.config.defaultViewMode).toUpperCase();
    modeIndicatorContainer.style.display = 'block';
} else {
    modeIndicatorContainer.style.display = 'none';
}
```

### Key Change
- **Target Changed:** From `.photoshow-mode-indicator` (span) to `.photoshow-viewer-controls` (div)
- **Effect:** Hides the entire container including its semi-transparent background
- **Result:** Clean UI with no visual artifacts when disabled

### CSS Involved
```css
.photoshow-viewer-controls {
    position: absolute;
    top: 8px;
    right: 8px;
    background: rgba(0, 0, 0, 0.6);  /* This was staying visible */
    color: white;
    padding: 4px 8px;
    border-radius: 4px;
    font-size: 11px;
    font-weight: bold;
}
```

This background is now properly hidden along with the text when the setting is disabled.
