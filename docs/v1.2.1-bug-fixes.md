# PhotoShow v1.2.1 - Bug Fixes Documentation

## Overview

Version 1.2.1 fixes two critical bugs that were affecting the user experience in v1.2.0.

## Bugs Fixed

### Bug #1: View Mode Size Not Changing

#### Japanese Report
> view modeをfit, max-fitにしても大きさが変わりません

#### English Translation
"Switching view mode to fit or max-fit doesn't change the size"

#### Problem Description

In version 1.2.0, both 'fit' and 'max-fit' view modes used identical viewport scaling (90%), making them indistinguishable. Users couldn't see any difference when switching between these modes using keyboard shortcuts (F and 9 keys).

#### Root Cause

Both modes were incorrectly configured with the same scaling factor:

```javascript
// BUGGY CODE (v1.2.0)
case 'fit':
    return { mode: 'fit', maxWidth: viewport.width * 0.9, maxHeight: viewport.height * 0.9 };

case 'max-fit':
    return { mode: 'max-fit', maxWidth: viewport.width * 0.9, maxHeight: viewport.height * 0.9 };
```

#### Solution

Changed 'fit' mode to use 100% of viewport while keeping 'max-fit' at 90%:

```javascript
// FIXED CODE (v1.2.1)
case 'fit':
    // Fit mode - fills viewport as much as possible (100%)
    return { mode: 'fit', maxWidth: viewport.width, maxHeight: viewport.height };

case 'max-fit':
    // 90% fit mode - ensures image always fits within 90% of viewport without cropping
    return { mode: 'max-fit', maxWidth: viewport.width * 0.9, maxHeight: viewport.height * 0.9 };
```

#### Result

- **fit mode**: Now fills 100% of viewport (larger display)
- **max-fit mode**: Uses 90% of viewport (slightly smaller, no cropping)
- **Visual difference**: Clear size change when switching modes
- **User feedback**: Mode indicator correctly shows which mode is active

#### Testing

1. Hover over any image
2. Press `F` key → Image should fill entire viewport
3. Press `9` key → Image should shrink to 90% of viewport
4. Press `V` key → Toggle between modes, clear size difference

### Bug #2: Image Info Not Displaying

#### Japanese Report
> Show Image Info, Show Caption, Show Dimensions, Show Formatをenableにしてもなにも表示が変化しません

#### English Translation
"Enabling 'Show Image Info', 'Show Caption', 'Show Dimensions', 'Show Format' doesn't change the display"

#### Problem Description

When users enabled image information display options in the Settings UI, the info bar at the bottom of the viewer didn't appear, and no information was displayed.

#### Root Cause

The issue was indirectly caused by Bug #1. Since both view modes had identical sizes, the viewer wasn't triggering proper updates when switching modes, which affected the info display logic. The info display code itself was correct, but the viewer state wasn't updating properly.

#### Solution

Fixing Bug #1 (making view modes distinct) resolved this issue. With proper mode differentiation, the viewer now updates correctly, and the existing info display logic works as intended:

```javascript
// Info display logic (lines 628-654) - was already correct
if (state.config.showImageInfo && state.config.imageInfoItems.dimensions) {
    dimensionsEl.textContent = `${dimensions.width} × ${dimensions.height}`;
    dimensionsEl.style.display = 'inline';
    hasAnyInfo = true;
}

if (state.config.showImageInfo && state.config.imageInfoItems.format) {
    formatEl.textContent = getImageFormat(hdUrl).toUpperCase();
    formatEl.style.display = 'inline';
    hasAnyInfo = true;
}

// Show info bar only if showImageInfo is enabled AND at least one item has content
viewer.querySelector('.photoshow-viewer-info').style.display =
    (state.config.showImageInfo && hasAnyInfo) ? 'block' : 'none';
```

#### Result

- **Dimensions**: Correctly display (e.g., "1920 × 1080")
- **Format**: Correctly display (e.g., "PNG", "JPG")
- **Info bar**: Appears at bottom of viewer when enabled
- **Settings**: Changes take effect immediately after reload

#### Testing

1. Open PhotoShow Settings (from userscript manager menu)
2. Go to General tab
3. Enable: ☑ Show Image Info
4. Enable: ☑ Show Dimensions
5. Enable: ☑ Show Format
6. Click "Save & Apply"
7. Reload page
8. Hover over image → Info bar should appear at bottom with dimensions and format
