# PhotoShow v1.4.0 - 実際の修正内容

## 深くお詫び申し上げます

v1.3.0 および v1.2.1 では、報告された問題が正しく修正されていませんでした。
テストを十分に行わず、表面的な修正のみを行ってしまいました。

**v1.4.0 では、根本原因を特定し、実際に問題を修正しました。**

---

## 🐛 問題の根本原因

### 問題1: 画像情報が表示されない

**報告された症状:**
- Show Image Info, Show Caption, Show Dimensions, Show Format を有効にしても何も表示されない

**根本原因:**
```css
/* 情報バーのCSS (v1.3.0まで - 間違い) */
.photoshow-viewer-info {
    position: absolute;  /* ← これが原因！ */
    bottom: 0;
    left: 0;
    right: 0;
}
```

情報バーが `position: absolute; bottom: 0` で配置されていたため:
- ビューワーコンテナの**内側**に絶対配置される
- 画像の**下部に重なって**表示される
- 画像と情報バーが重なって見えない
- v1.3.0 では計算でスペースを確保しようとしたが、CSS が absolute のままだったため効果なし

### 問題2: ビューモードがすべて使い物にならない

**報告された症状:**
- view mode を fit, max-fit に変更してもサイズが変わらない
- どのモードも似たようなサイズ

**根本原因:**
```javascript
// v1.3.0 のパーセンテージ (似すぎている)
'fit':     (viewport.width - 40) → 約85%
'max-fit': (viewport.width - 40) * 0.9 → 約77%

// 差が小さすぎて視覚的に区別できない！
```

- パーセンテージの差が小さすぎた (85% vs 77%)
- 複雑な計算 (padding, info bar height) で差が更に小さくなった
- 結果: どのモードも似たようなサイズに見えた

## ✅ v1.4.0 の修正内容

### 修正1: CSS 構造の変更

**変更箇所: photoshow.user.js 行 1102-1111**

```css
/* BEFORE (v1.3.0 - 間違い): */
.photoshow-viewer-info {
    position: absolute;  /* ← 画像に重なる */
    bottom: 0;
    left: 0;
    right: 0;
    padding: 8px 12px;
    background: rgba(0, 0, 0, 0.7);
}

/* AFTER (v1.4.0 - 修正): */
.photoshow-viewer-info {
    /* position: absolute を削除 */
    /* 通常のドキュメントフローで表示 */
    padding: 8px 12px;
    background: rgba(0, 0, 0, 0.7);
    width: 100%;
    box-sizing: border-box;
}
```

**効果:**
- ✅ 情報バーが画像の**下**に自然に表示される
- ✅ 画像と情報バーが重ならない
- ✅ 寸法が表示される: "1920 × 1080"
- ✅ フォーマットが表示される: "PNG", "JPG"

### 修正2: アルゴリズムの簡略化

**変更箇所: photoshow.user.js 行 620-641**

```javascript
// BEFORE (v1.3.0 - 複雑すぎ):
const padding = 16;
const infoBarHeight = needsInfoBar ? 44 : 0;
const maxImageWidth = viewMode.maxWidth - (padding * 2);
const maxImageHeight = viewMode.maxHeight - (padding * 2) - infoBarHeight;
// ... さらに30行の複雑な計算

// AFTER (v1.4.0 - シンプル):
const scale = Math.min(
    viewMode.maxWidth / dimensions.width,
    viewMode.maxHeight / dimensions.height,
    1
);
const displayWidth = Math.round(dimensions.width * scale);
const displayHeight = Math.round(dimensions.height * scale);
viewer.style.height = 'auto'; // 自動サイズ調整
```

**効果:**
- ✅ コードが30行以上シンプルになった
- ✅ 情報バーのスペースを手動で計算する必要がなくなった
- ✅ ブラウザが自動的にレイアウトを処理
- ✅ 保守性が向上

### 修正3: 明確なビューモードのパーセンテージ

**変更箇所: photoshow.user.js 行 527-555**

```javascript
// 新しいパーセンテージ (明確に異なる):
'fit':      95%  // 最大 - 画面いっぱい
'max-fit':  75%  // 明らかに小さい
'auto':     85%  // バランス
'lite':     35%  // 中サイズプレビュー
'mini':     20%  // 小サイズプレビュー
```

**効果:**
- ✅ 各モードが**明らかに**異なるサイズ
- ✅ モードを切り替えると**はっきり**変化が分かる
- ✅ fit (F) と max-fit (9) の違いが一目瞭然

## 💡 なぜこの修正が機能するのか

### 1. CSS 構造の修正
- `position: absolute` を削除することで、情報バーが通常のドキュメントフローに従う
- 画像の後に自然に配置されるため、重ならない
- ブラウザが自動的に適切なレイアウトを計算

### 2. アルゴリズムの簡略化
- 複雑な padding/info bar の計算を削除
- シンプルなスケール計算のみ
- `height: 'auto'` でブラウザに任せる
- コードが読みやすく、バグが入りにくい

### 3. 明確なパーセンテージ
- 95% vs 75% vs 35% vs 20% → 明らかに異なる
- ユーザーが視覚的に区別できる
- モード切替の効果がはっきりわかる

## 🎯 以前の修正が失敗した理由

### v1.3.0 の失敗
1. **CSS は absolute のまま** → 情報バーが重なる問題は解決せず
2. **計算で空きスペースを確保** → CSS が absolute なので効果なし
3. **パーセンテージが似すぎ** → 85% vs 77% では差が小さすぎ
4. **テストが不十分** → 実際に動作確認せず

### v1.2.1 の失敗
1. **fit と max-fit が同じ値** → 90% vs 90%
2. **根本的な CSS 問題を無視** → 情報バー表示は修正せず

### v1.4.0 の成功
1. **CSS 構造を修正** → absolute を削除
2. **アルゴリズムを簡略化** → 複雑な計算を削除
3. **明確なパーセンテージ** → 95%, 75%, 35%, 20%
4. **包括的にテスト** → test-v1.4.0-real-fix.html で確認
