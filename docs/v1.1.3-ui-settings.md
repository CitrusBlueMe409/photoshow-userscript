# PhotoShow v1.1.3 - UI Settings Enhancement

## Overview

Version 1.1.3 adds two important UI customization features based on user feedback:

1. **Show View Mode Indicator Setting** - Toggle visibility of the mode indicator (AUTO, FIT, etc.) in the top-right corner
2. **Conditional Info Bar Display** - Automatically hide the semi-transparent bottom bar when all image info items are disabled

## Features

### 1. View Mode Indicator Toggle

**Location:** Settings → General Tab → "Show View Mode Indicator"

**Description:** Controls whether the view mode indicator is displayed in the top-right corner of the viewer.

**Default:** Enabled (checked)

**Behavior:**
- When **enabled**: Mode indicator (AUTO, FIT, LITE, MINI, PANORAMIC) is visible
- When **disabled**: Mode indicator is completely hidden

**Use Case:** Users who prefer a minimal UI can hide the mode indicator while keeping image information visible.

### 2. Conditional Info Bar Display

**Location:** Settings → General Tab → Image Information section

**Description:** The semi-transparent info bar at the bottom of the viewer now intelligently hides itself when no information is available to display.

**Behavior:**
- Info bar **shows** when:
  - "Show Image Info" is enabled AND
  - At least one of the following has content:
    - Caption (if enabled and image has caption)
    - Dimensions (if enabled)
    - Format (if enabled)

- Info bar **hides** when:
  - "Show Image Info" is disabled OR
  - All image info items (Caption, Dimensions, Format) are disabled

**Use Case:** Eliminates the empty semi-transparent bar that would appear when all info items were disabled.

## Usage Scenarios

### Scenario 1: Default (Everything Enabled)
- **View Mode Indicator:** ✅ Visible in top-right (e.g., "AUTO")
- **Info Bar:** ✅ Visible at bottom with caption, dimensions, and format
- **Best for:** Users who want all information displayed

### Scenario 2: Hide Mode Indicator Only
- **View Mode Indicator:** ❌ Hidden
- **Info Bar:** ✅ Visible at bottom
- **Best for:** Users who know their preferred mode and don't need the reminder

### Scenario 3: Hide Info Bar Only
- **View Mode Indicator:** ✅ Visible in top-right
- **Info Bar:** ❌ Hidden (all info items disabled)
- **Best for:** Users who want to see the mode but not image details

### Scenario 4: Minimal UI (Everything Hidden)
- **View Mode Indicator:** ❌ Hidden
- **Info Bar:** ❌ Hidden
- **Best for:** Distraction-free viewing with clean, minimal interface
- **Result:** Only the image is displayed, no overlays whatsoever ✨

## Implementation Details

### Code Changes

**File:** `photoshow.user.js`

**1. Configuration (Line 51)**
```javascript
showViewModeIndicator: true,  // NEW setting added
```

**2. Viewer Display Logic (Lines 544-587)**
- Refactored to track if any info should be displayed with `hasAnyInfo` flag
- Info bar only displays when `showImageInfo` is true AND `hasAnyInfo` is true
- Mode indicator visibility controlled by `showViewModeIndicator` setting
- Each info item (caption, dimensions, format) individually shows/hides based on settings

**3. Settings UI (Lines 1361-1369)**
- Added checkbox control for "Show View Mode Indicator"
- Located in General tab under Image Information section

**4. Settings Save Logic (Line 1686)**
- Added `showViewModeIndicator` to configuration save/load

## Migration Guide

### Upgrading from v1.1.2 or earlier

**No action required!** The new settings have sensible defaults:
- `showViewModeIndicator` defaults to `true` (enabled)
- Existing configurations will work exactly as before

### Resetting to Defaults

If you want to reset all settings to defaults:

```javascript
// Open browser console (F12) and run:
window.resetPhotoShowSettings()
```
