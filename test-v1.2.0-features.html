🎉 PhotoShow v1.2.0 - Feature Test Page

📋 Prerequisites

  1. Install PhotoShow v1.2.0 userscript in Tampermonkey/Greasemonkey/Violentmonkey
  2. Ensure PhotoShow is enabled
  3. Open Settings (userscript manager menu → "PhotoShow Settings")
  4. Enable Debug Mode in Advanced tab to see console logs

3️⃣ Exception URL List (GUI)

Japanese: 例外URLをリスト形式でGUIで設定

How to Test:

  1. Open Settings → Advanced Tab
  2. Find "Exception URLs" textarea
  3. Add one of these patterns:
    *placeholder.com/400x300/E74C3C*
    https://via.placeholder.com/400x300/3498DB*
  4. Save settings and reload page
  5. Try hovering over images - matching ones should be ignored

4️⃣ Debug Mode Toggle

Japanese: Debug modeのオンオフトグル

How to Test:

  1. Open browser console (F12 → Console tab)
  2. With Debug Mode OFF (default):
    • Hover over images
    • Console should be clean (no PhotoShow logs)
  3. Open Settings → Advanced Tab
  4. Check "Debug Mode" checkbox
  5. Save and reload page
  6. With Debug Mode ON:
    • Hover over images
    • Console should show logs: [PhotoShow] Image detected:...
Expected Console Output (Debug Mode ON): [PhotoShow] Image detected: https://via.placeholder.com/... [PhotoShow] showViewer called with: https://... [PhotoShow] HD URL: https://...
