🐛 Bug Fix #1: View Mode Size Changes

❌ Original Bug: Switching to 'fit' or 'max-fit' mode didn't change image size
✅ Fixed in v1.2.1: 'fit' and 'max-fit' now have distinct sizes
  • fit mode: Uses 100% of viewport (fills screen)
  • max-fit mode: Uses 90% of viewport (slightly smaller, no cropping)

❌ Before (v1.2.0)

fit: 90% viewport
max-fit: 90% viewport
Result: Both identical!

✅ After (v1.2.1)

fit: 100% viewport
max-fit: 90% viewport
Result: Clearly different sizes!

🧪 Test Instructions:

  1. Enable PhotoShow userscript
  2. Hover over any image below
  3. Press F to switch to FIT mode
  4. Observe the image size (should fill viewport)
  5. Press 9 to switch to MAX-FIT mode
  6. Observe the image size (should be slightly smaller, 90%)
  7. Press V to toggle between modes
  8. You should see a clear size difference now!

🐛 Bug Fix #2: Image Info Display

❌ Original Bug: Enabling "Show Image Info", "Show Caption", "Show Dimensions", "Show Format" didn't display anything
✅ Fixed in v1.2.1: Image information now displays correctly
  • Dimensions: Shows image width × height
  • Format: Shows file format (JPG, PNG, etc.)
  • Info bar: Appears at bottom when enabled
⚙️ Settings Configuration:
  1. Open PhotoShow Settings (userscript manager menu)
  2. Go to General tab
  3. Check ☑ Show Image Info
  4. Check ☑ Show Dimensions
  5. Check ☑ Show Format
  6. Click Save & Apply
  7. Reload this page

🧪 Test Instructions:

  1. Enable PhotoShow and configure settings as above
  2. Hover over any image below
  3. Look at the bottom of the viewer
  4. You should see a semi-transparent bar with:

    • File format (e.g., "PNG")
  5. Try different view modes (F, 9, A, L, M, P)
  6. Info bar should remain visible in all modes
