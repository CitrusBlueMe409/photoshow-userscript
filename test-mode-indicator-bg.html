PhotoShow - Mode Indicator Background Bug Fix Test

🐛 Bug Description BUG

Issue: When "Show View Mode Indicator" setting is disabled:
  • ✅ The text (AUTO, FIT, LITE, etc.) disappears correctly
  • ❌ The semi-transparent background box remains visible (BUG)

Expected: Both the text AND the background should disappear when the setting is disabled.

🔧 Fix Applied FIXED

Solution: Instead of hiding only the .photoshow-mode-indicator span, now we hide the entire .photoshow-viewer-controls container which has the semi-transparent background.

Code Change:

// Before (BUG): const modeIndicator = viewer.querySelector('.photoshow-mode-indicator'); if (state.config.showViewModeIndicator) { modeIndicator.style.display = 'block'; } else { modeIndicator.style.display = 'none'; // Only hides text, not background! } // After (FIXED): const modeIndicatorContainer = viewer.querySelector('.photoshow-viewer-controls'); const modeIndicator = viewer.querySelector('.photoshow-mode-indicator'); if (state.config.showViewModeIndicator) { modeIndicatorContainer.style.display = 'block'; // Shows entire container } else { modeIndicatorContainer.style.display = 'none'; // Hides entire container including background }

🧪 Test Instructions

  1. Open PhotoShow Settings from your userscript manager menu
  2. In the General tab, find the "Show View Mode Indicator" checkbox
  3. Make sure PhotoShow is enabled and whitelistMode is disabled (or site is whitelisted)
  4. Close the settings and hover over the test images below
