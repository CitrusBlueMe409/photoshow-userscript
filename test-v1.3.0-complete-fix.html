🐛 修正された問題 (Fixed Issues)

Issue #1: 画像情報が表示されない (Image Info Not Displaying)

日本語: Show Image Info, Show Caption, Show Dimensions, Show Formatをenableにしてもなにも表示が変化しません

English: Enabling "Show Image Info", "Show Caption", "Show Dimensions", "Show Format" doesn't change the display

根本原因 (Root Cause): 情報バーが画像と重なっていた / Info bar overlapped the image

Issue #2: ビューモードが機能しない (View Modes Not Working)

日本語: view modeがすべて使い物になりません

English: All view modes are unusable

根本原因 (Root Cause): すべてのモードが同じサイズに見えた / All modes looked the same size

✅ 解決方法 (Solution)

完全なアルゴリズムの書き直し (Complete Algorithm Rewrite):

  • ビューアコンテナが画像+パディング+情報バーを含む / Viewer container now includes image + padding + info bar
  • 情報バーは画像の外側に配置 / Info bar positioned outside image area
  • 各ビューモードが異なるサイズを持つ / Each view mode has distinct size
  • 適切な余白とスペース計算 / Proper margin and space calculation

❌ 旧コード (Old Code)

// Viewer = Image size only
const displayWidth = imageWidth * scale;
const displayHeight = imageHeight * scale;

viewer.style.width = displayWidth + 'px';
viewer.style.height = displayHeight + 'px';

// Info bar overlaps image!
// No space reserved!

✅ 新コード (New Code)

// Reserve space first
const padding = 16;
const infoBarHeight = needsInfoBar ? 44 : 0;

// Calculate available space
const maxImageWidth = viewMode.maxWidth - (padding * 2);
const maxImageHeight = viewMode.maxHeight - (padding * 2) - infoBarHeight;

// Scale image to fit available space
const scale = Math.min(maxImageWidth / imageWidth, maxImageHeight / imageHeight, 1);
const displayWidth = imageWidth * scale;
const displayHeight = imageHeight * scale;

// Container includes everything
const containerWidth = displayWidth + (padding * 2);
const containerHeight = displayHeight + (padding * 2) + infoBarHeight;

viewer.style.width = containerWidth + 'px';
viewer.style.height = containerHeight + 'px';
