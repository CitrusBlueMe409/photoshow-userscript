📋 PhotoShow UI Settings Test Page

🎯 Test Purpose

This page tests the new UI settings added in v1.1.3:

  1. Show View Mode Indicator - Control visibility of mode indicator (AUTO, FIT, etc.) in top-right
  2. Conditional Info Bar - Hide semi-transparent bottom bar when all image info items are disabled

📝 Test Instructions

Before starting: Make sure PhotoShow userscript is installed and enabled.

Test 1: View Mode Indicator Toggle

  1. Open PhotoShow Settings (from userscript manager menu)
  2. Go to General tab
  3. Find "Show View Mode Indicator" setting
  4. Check the box (enabled by default)
  5. Hover over images below → Should see mode indicator in top-right (e.g., "AUTO")
  6. Open Settings again, uncheck "Show View Mode Indicator"
  7. Save and reload page
  8. Hover over images → Mode indicator should be HIDDEN

Test 2: Info Bar Conditional Display

  1. Open PhotoShow Settings → General tab
  2. Ensure "Show Image Info" is checked
  3. Check all three items: Caption, Dimensions, Format
  4. Save and hover over images → Should see semi-transparent bar at bottom with info
  5. Open Settings again
  6. Uncheck "Show Caption"
  7. Save and hover → Should still see bar (Dimensions + Format)
  8. Open Settings, uncheck "Show Dimensions"
  9. Save and hover → Should still see bar (Format only)
  10. Open Settings, uncheck "Show Format" (all items now disabled)
  11. Save and hover → Semi-transparent bar should be HIDDEN

Test 3: Combined Test

  1. Disable both View Mode Indicator AND all Image Info Items
  2. Hover over images → No overlays at all (clean viewer)
  3. Re-enable one or both → Overlays appear as expected

🖼️ Test Images

✅ Test Checklist

  • View mode indicator visible when setting is enabled
  • View mode indicator hidden when setting is disabled
  • Info bar visible when any image info item is enabled
  • Info bar visible when only one image info item is enabled
  • Info bar hidden when all image info items are disabled
  • Info bar respects "Show Image Info" master toggle
  • Both settings work independently
  • Both can be disabled simultaneously for minimal UI
  • Settings persist after page reload
  • No JavaScript errors in console

🔍 Expected Results

Scenario 1: All enabled (default)

View Mode Indicator: Visible in top-right (e.g., "AUTO")
Info Bar: Visible at bottom with caption, dimensions, and format

Scenario 2: View Mode disabled, Info enabled

View Mode Indicator: Hidden
Info Bar: Visible at bottom

Scenario 3: View Mode enabled, all Info items disabled

View Mode Indicator: Visible in top-right
Info Bar: Hidden (no semi-transparent bar)

Scenario 4: Both disabled

View Mode Indicator: Hidden
Info Bar: Hidden
Result: Clean viewer with only the image (minimal UI)

🐛 Debug Information

Open browser console (F12) to see PhotoShow debug logs:

  • [PhotoShow] Image detected - When hovering over image
  • [PhotoShow] showViewer called - When viewer is displayed
  • Check for any errors related to showViewModeIndicator or info bar display
