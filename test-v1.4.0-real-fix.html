  3. 以下を有効化:
    • ☑ Enable PhotoShow
    • ☑ Show Image Info
    • ☑ Show Dimensions
    • ☑ Show Format
  4. Save & Apply をクリック
  5. このページをリロード (F5)
  6. ブラウザの開発者ツールを開く (F12) - コンソールを確認

Test 2: ビューモードが正しく機能するか？ (View Modes)

✅ 期待される動作:

  • F キー: Fit モード → 画面の 95% に拡大 (最大)
  • 9 キー: Max-Fit モード → 画面の 75% に縮小 (明らかに小さい)
  • L キー: Lite モード → 画面の 35% (プレビュー)
  • M キー: Mini モード → 画面の 20% (小さいプレビュー)
  • 各モードで明らかにサイズが異なる

❌ v1.3.0 (間違い)

  • Fit: 85%, Max-Fit: 77% → 似ている
  • モード切替でほとんど変化なし
  • どのモードか分からない

✅ v1.4.0 (修正済み)

  • Fit: 95%, Max-Fit: 75% → はっきり違う
  • モード切替で明らかな変化
  • 各モードが識別可能
