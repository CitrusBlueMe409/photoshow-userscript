📋 事前準備 (Pre-Test Setup)

1. PhotoShow v2.0.0 がインストールされていることを確認

ユーザースクリプトマネージャーで PhotoShow のバージョンが 2.0.0 であることを確認してください。

2. 設定を確認

設定 → General タブ:

  • ☑ Enable PhotoShow
  • ☑ Show Image Info
  • 必要に応じて Show Caption, Show Dimensions, Show Format を個別にON/OFF

3. ブラウザのコンソールを開く (オプション)

F12 キーを押してコンソールを開き、デバッグメッセージを確認できます

✅ テスト1: 画像情報表示の修正 (Info Display Fix)

問題: 1項目だけ有効にしても表示されない、2項目で1つしか表示されない

修正: どの組み合わせでも正しく表示される

テスト手順:

  1. 設定で Show Dimensions のみを有効にする
  2. 下の画像にホバー → "800 × 600" だけが表示されることを確認 ✅
  3. 設定で Show Format も追加で有効にする
  4. 再度ホバー → "800 × 600 | PNG" と両方表示されることを確認 ✅
  5. 設定で Show Caption も追加で有効にする
  6. 再度ホバー → 3つすべて表示されることを確認 ✅

✅ 期待される結果:

  • 1項目のみ有効: その1項目だけが表示される
  • 2項目有効: 2項目が " | " で区切られて表示される (例: "800 × 600 | PNG")
  • 3項目有効: すべてが区切られて表示される
  • 情報バーの背景が半透明 (rgba(0, 0, 0, 0.75))

✅ テスト2: ビューモードの修正 (View Mode Fix)

問題: すべてのビューモードが使い物にならない、90%はビューポートに対する割合

修正: 正しいパーセンテージを使用 (fit=98%, max-fit=90%)

テスト手順:

  1. 下の画像にホバーする
  2. F キーを押す → 画像が98%のサイズ (ほぼ全画面) になることを確認 ✅
  3. 9 キーを押す → 画像が90%のサイズ (明らかに小さい) になることを確認 ✅
  4. L キーを押す → 画像が40%のサイズ (中プレビュー) になることを確認 ✅
  5. M キーを押す → 画像が25%のサイズ (小プレビュー) になることを確認 ✅
  6. V キーを押す → モードが切り替わることを確認 ✅
